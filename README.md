# ulibc

Historically first C standard library for Utopia that emerged from [finit](https://github.com/MoreUtopia/finit).

Made to be easibly embeddable into applications - create a Git submodule, then instruct your build system to compile ulibc's sources in `src` and add `include/` to include directories.

We do not follow any standards in this library, because why would we (ragebait).
